## 🖥️ Sobre o projeto

A **Tech.system** é uma proposta de empresa fictícia que reúne serviços relacionados à segurança e à experiência digital. A página apresenta a empresa, explica sua proposta e destaca os serviços oferecidos, com um caminho para a área de login.

O visual segue uma identidade **escura e sofisticada**, combinando tons de preto e azul-acinzentado com detalhes dourados. A ideia é transmitir tecnologia, confiança e profissionalismo sem transformar a página em mais um festival de gradientes aleatórios.

## ✨ O que a página apresenta

- **Apresentação institucional:** introdução à Tech.system e à sua proposta.
- **Serviços em destaque:** tecnologias de segurança, VPNs, descontos em plataformas de streaming e conectividade.
- **Acesso ao login:** link para a página de login do projeto.
- **Identidade visual própria:** fundo com imagem, camadas escuras, detalhes dourados, sombras e cartões de conteúdo.
- **Organização visual:** cabeçalho, seções de conteúdo e rodapé.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Função no projeto |
| --- | --- |
| **HTML5** | Estrutura e organização do conteúdo da página. |
| **CSS3** | Cores, tipografia, espaçamento, fundos, bordas, sombras e apresentação visual. |

## 🎨 Destaques do CSS

O arquivo de estilos foi organizado para manter uma aparência consistente:

- `box-sizing: border-box` para facilitar o controle das dimensões dos elementos.
- `scroll-behavior: smooth` para uma rolagem mais suave.
- Gradientes escuros e uma imagem de fundo para compor o cenário visual.
- Paleta com tons escuros e dourado (`#b89b5e` e `#d6bd7a`).
- Seções centralizadas com largura limitada, espaçamento interno, bordas e sombras.
- Estilização dos marcadores das listas e do rodapé para manter a identidade visual.

## 📁 Estrutura do projeto

```text
Atividade/
├── index.html
├── style.css
├── img/
│   └── background.jpg
└── login/
    └── login.html
```

O HTML principal carrega o CSS pelo arquivo `style.css`. A imagem de fundo é referenciada em `img/background.jpg`, e o link de acesso direciona para `login/login.html`.

## ▶️ Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Para visualizar o resultado esperado, mantenha os caminhos dos arquivos e das pastas iguais aos utilizados no HTML e no CSS.

Se preferir usar o Git:

```bash
git clone https://github.com/machadodeassisll76blip/Atividade.git
cd Atividade
```

Depois, abra o `index.html` no navegador.

- Relação entre arquivos HTML e CSS.
- Construção gradual de uma identidade visual.
